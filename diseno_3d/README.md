# Diseños 3D — Cobot HerkuleX

Los diseños de esta carpeta corresponden al prototipo de robot colaborativo (cobot) del **Proyecto Final de Tecnólogo en Mecatrónica** de UTEC (ITR Suroeste, Fray Bentos), construido con servomotores HerkuleX DRS-0602 y efector piCOBOT.

## Estructura

| Carpeta | Contenido |
|---------|-----------|
| `fuente/` | Archivos CAD **editables** originales (p. ej. Fusion 360, STEP u otros formatos nativos del software usado). |
| `export/` | Archivos **exportados** para fabricación o impresión 3D (p. ej. STL, 3MF). |

## Estado

Todavía deben incorporarse:

- las exportaciones validadas correspondientes a esa misma versión.

Hasta entonces, estas carpetas permanecen como estructura preparada para la continuidad del proyecto.
