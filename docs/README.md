## Estructura del template oficial (resumen)

| Sección | Contenido |
|---------|-----------|
| Portada | Título, autor, C.I., ITR Suroeste, Sede Fray Bentos, Carrera, correo, tutor, fecha |
| Declaración de autoría | Texto estándar con firma |
| Agradecimientos | Formal, instituciones/personas que apoyaron |
| Resumen | 1 párrafo, máx. 250 palabras, qué se hizo/encontró/concluyó |
| Abstract | Versión en inglés + palabras clave en ambos idiomas |
| **Cap. 1 – El problema** | 1.1 Planteamiento, 1.2 Objetivos (general y específicos), 1.3 Alcance y limitaciones |
| **Cap. 2 – Marco teórico** | Antecedentes + bases teóricas |
| **Cap. 3 – Desarrollo** | Por objetivo específico: metodología, procedimientos, equipos, datos |
| **Cap. 4 – Resultado y análisis** | Por objetivo: mediciones, cálculos, análisis |
| Conclusiones | Lista numerada, oraciones breves |
| Recomendaciones y trabajos futuros | Oportunidades de mejora o extensión |
| Bibliografía | APA 7, orden de aparición |
| Anexo | Tablas, gráficas, planos, fotos de equipos |
| Índice de tablas / Índice de figuras | Al final |
